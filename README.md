# 负产阶级 2

一款以「债务与经营」为核心的网页模拟游戏：想办法把债还清，并在过程中经营自己的生活。

> 这是「负产阶级」的第二个版本，与 [fuchan-jieji](https://github.com/houhuizhang80-wq/fuchan-jieji) 内容不同、各自独立，可以都玩。

## 在线试玩

<https://houhuizhang80-wq.github.io/fuchan-jieji-2/>

打开即玩，不需要账号、不需要后端。

## 本地游玩

整个游戏就是一个 `index.html`（约 2.0 MB，无外部依赖）：

```
双击 index.html 即可
```

## 玩法要点

- **清债主线**：围绕「清债与经营」推进，把债还清是核心目标。
- **投资与黑市**：通过投资页进行资金运作，黑市有高回报也有风险。
- **银行与贷款**：可借贷周转，但利息会滚。
- **目标系统**：目标页给出阶段性任务，完成后领取奖励。
- **成长元素**：技能点、声望、荣誉入殿，以及孩子成长线，都会影响后续走向。
- **资源**：余额、手续费、免广告券等，需要精打细算。

## 技术说明

- 纯前端单文件，HTML + 内联 CSS/JS，无构建、无后端、无网络请求。
- 存档在浏览器本地（localStorage），清缓存会丢档。
- 建议通过 HTTP 打开（如 `python -m http.server`），`file://` 下部分浏览器会限制 localStorage。
